# Daily Newsletter

A Python-based application to generate daily newsletters from RSS feeds and send them via email.

## Features
- Parse RSS feeds
- Generate formatted email newsletters
- Customize newsletter templates
- Manage multiple RSS sources

## Installation
See requirements.txt for dependencies.

## Configuration
Copy `.env.example` to `.env` and configure your API keys and settings.

## Claude Cowork Scheduled Task
Use [COWORK_SCHEDULED_TASK.md](COWORK_SCHEDULED_TASK.md) to run the newsletter as a Claude Cowork scheduled task.
